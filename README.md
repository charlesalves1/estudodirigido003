# Estudo Dirigido 003 – Estruturas, Funções e Organização em Python

## 📌 Descrição
Repositório criado para armazenar os exercícios do terceiro estudo dirigido em Python, com foco no aprimoramento da lógica de programação, organização do código e uso mais estruturado de funções.

Este estudo aprofunda os conceitos trabalhados nos estudos anteriores, reforçando a construção de soluções mais organizadas e reutilizáveis.

## 🌿 Estrutura de Branches
Este repositório possui mais de uma branch para organização do desenvolvimento:

- **main**: versão principal com os exercícios finalizados
- **branch secundária**: utilizada para testes, variações de solução ou evolução dos exercícios

Essa separação reflete boas práticas iniciais de versionamento com Git.

## 🎯 Conteúdos Trabalhados
- Estruturas condicionais avançadas
- Laços de repetição
- Funções e modularização
- Organização e reutilização de código
- Resolução de problemas com lógica computacional
- Boas práticas iniciais de desenvolvimento
